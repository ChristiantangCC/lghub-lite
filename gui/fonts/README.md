# Fonts

Bundled into `lghub-lite-gui.exe` so the app matches its design. All are under the SIL Open
Font License 1.1; each licence text is next to its fonts.

| File | Font | Licence |
|---|---|---|
| `LLSans-Regular/Medium/SemiBold.ttf` | IBM Plex Sans, trimmed to Latin and renamed "LL Sans" | `LLSans-LLMono-OFL.txt` |
| `LLMono-Regular/SemiBold.ttf` | IBM Plex Mono, trimmed to Latin and renamed "LL Mono" | `LLSans-LLMono-OFL.txt` |
| `SpaceGrotesk-wght.ttf` | Space Grotesk (variable weight), trimmed to Latin | `SpaceGrotesk-OFL.txt` |
| `VT323-Regular.ttf` | VT323, trimmed to Latin | `VT323-OFL.txt` |

IBM Plex has the Reserved Font Name "Plex", so the trimmed copies (modified versions under the
OFL) carry a different name. Sources: github.com/IBM/plex, github.com/google/fonts.
Trimmed with fontTools `subset` to Basic Latin, Latin-1 and a few punctuation marks
(– — ‘ ’ “ ” • … − ≈ ← ↑ → ↓ ≤ ≥ · ×).
